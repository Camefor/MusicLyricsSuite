思路：

第一步 传入歌曲名称，搜索歌曲基本信息：

https://api.liriqo-alfarrizi.my.id/v1/search?title=%E6%9D%8E%E5%BF%97%20-%20%E5%A2%99%E4%B8%8A%E7%9A%84%E5%90%91%E6%97%A5%E8%91%B5(2014i%EF%BC%8FO%E7%89%88)&artist=%E6%9D%8E%E5%BF%97&album=iO%202014%20Live&duration=199

接口响应：
```
{
  "isVideoId": true,
  "videoId": "wVmcRuF5wNs",
  "source": "youtube",
  "metadata": {
    "title": "牆上的向日葵（2016跨年版）",
    "artist": "李志",
    "album": "李志、電聲與管弦樂 (普通版)",
    "duration": ""
  },
  "matchScore": 1
}

```

如果 source 字段为  "youtube"，则提取 "videoId": "7NbzujopTUc"。




第二步 传入 videoId,查询歌词详情：
https://api.liriqo-alfarrizi.my.id/v1/lyrics?v=wVmcRuF5wNs
